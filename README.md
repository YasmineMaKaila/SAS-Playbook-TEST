# SAS Pod Playbook — internal review documents

**Do not publish these to a public repository or a public GitHub Pages site.**
They are working governance documents for SAS / Talent & Development reviewers, not
part of the learner-facing site. They list unresolved source questions and review flags.

| File | What it is |
|---|---|
| `sme-review-flag-report.md` | Source wording that was ambiguous or inconsistent and was preserved as written pending SME review |
| `content-reconciliation-report.md` | How every item of the approved Word source was classified into General vs. Property-Specific information |
| `property-naming-audit.md` | Every community named anywhere in the SAS source, checked against the approved portfolio listing |
| `naming-address-reconciliation.md` | Market names, official property names and addresses matched against the approved address spreadsheet |
| `property-website-reconciliation.md` | How property pages on cortland.com were matched, and how Cortland's own map works |

Some figures in the older reports (for example pod numbers and early map status) reflect the
state of the project when each report was written; the playbook's `README.md` lists the current open items.
